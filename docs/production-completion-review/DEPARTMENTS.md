# Review departments and dispatch

Nine staff assignments ran with at most three child agents alongside the orchestrator; later departments used released slots. Batch numbers show departmental groups, not simultaneous nine-agent execution. Each role has a separate prompt and report. The root reconciles duplicates and verifies candidate findings before changing the implementation catalog. These reviewers cannot independently accept financial or security policy.
