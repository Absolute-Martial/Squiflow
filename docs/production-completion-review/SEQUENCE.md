# Sequential production-completion milestones

This is a proposed dispatch plan derived from the current catalog and departmental review. It does not accept new business policy or qualify runtime. Product version stays **v0.0.1**. Current executable truth remains [README.IMPLEMENTATION.md](../../README.IMPLEMENTATION.md). A required task can be a decision or verification of existing work; a conditional task is not permission to omit a requested customer outcome.

Use this milestone table for understanding. For one-at-a-time assignment use [all catalog units](ALL_CATALOG_UNITS.md), then attach the full existing task file. Exact dependencies in [tasks.json](../development-tasks/tasks.json) override grouping below. Groups can overlap only after their individual dependencies are accepted and writable ownership is disjoint.

Stages 8, 9 and 11 are different authority tracks, not a universal business-time ordering. Billing and fulfillment remain separate; order commitment never implies either. Accepted deposits/partial invoices/credit require their own closed contracts. Stage 1 lists decision families, not an instruction to resolve all decisions in one agent task.

The current catalog intentionally makes Admin Web runtime delivery wait for GATE-003. This plan preserves that recorded order; an owner may review whether it is a product sequencing choice rather than a compile-time dependency. Decisions WEB-001/UIA-001 may be prepared early, but this review does not bypass the runtime gates.
