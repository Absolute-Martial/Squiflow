- Conditional operations: COM-016 purchasing/payables; COM-017 real outsourced work; COM-018 tracked inventory. Their actual financial/quantity semantics and activation disposition are explicit decisions.
- Billing: COM-019 closes the remaining contract choices → COM-020 qualifies/adapts incoming core → COM-021 atomic PostgreSQL → COM-022 authorized API. These original catalog assignments follow the current focused owner; the separately discussed issuance proposal is outside this package. Persistence does not depend on PDF/notifications.
- Financial completion: COM-023 receivable → COM-024 manual recorded/reconciled payment → COM-025 partial allocation/unapplied funds. Provider payments COM-026 and credit COM-027 require selection.
- Corrections/history: COM-028 reversible-work cancellation → COM-029 linked invoice credit/dispute → COM-030 actual return/manual refund → COM-031 retained statements/reports → COM-032 real commercial journey qualification.

Invoice and fulfillment chains can advance independently after their exact prerequisites. Team/profile/authority and operational dependencies are already bound to exact IDs in task metadata; no semantic mapping is left for an implementation agent to guess. All shared solution, model, migrator and package registrations use integrator ownership.
